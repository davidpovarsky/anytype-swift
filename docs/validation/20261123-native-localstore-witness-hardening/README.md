## Why this follow-up was needed

A Go interface with a private marker does not by itself prevent external embedding
and public-method overrides. The original six-method witness evidence at 74b5 remains
valid for what actually ran, but it did not prove an unforgeable issuer boundary.

Capture now requires a concrete *Capability whose acquisition closure is unexported.
Nil and zero values reject. There is no public or production issuer. The fixture
constructs the closure from its original issuer's bound method, so forwarding an
issued capability delegates the same owner/generation; retirement still refuses it.
Lease markers are not described as authority guarantees.

The opt-in external-package test helper exists only in export_test.go, absent from
the product package. This is a safe-Go API boundary, not a claim about unsafe memory
access or modifications to trusted package sources.
