## Source audit and narrow repair

The exact current 3552 source map retains limited jobs and local data. There is no overall retry-count cap: while genuine quota remains unavailable, the durable job may intentionally remain pending indefinitely, with paced retries and an explicit LIMITED state. That is not a busy-loop, data loss, or a successful recovery; consumers should expose the limited state rather than present it as ordinary progress. File-node ErrLimitExceeded maps to a typed limited error; the durable queue persists attempts/next time/error/Limited, backs limited jobs off ten minutes, and intentionally makes attempted jobs due at ordinary startup. Verified receipts remain necessary to mark durability. No source defect was demonstrated that converts zero quota to success or discards the pending original bytes.

A distinct broker gap is demonstrated in hedgeQuota: its original wait loop has no context Done arm, so it can outlive cancellation if a peer callback does not return. The proposed two-insertion repair returns the coordinator on cancellation and rejects pre-cancelled entry. It does not terminate an arbitrary callback. The original len(peers) answer buffer remains; tests release blocked callbacks and join the test-owned coordinator, with conditional callback-return observation on early entry failure. This is not attributed to Alice's historical quota result.

The broker packet is SOURCE_ONLY and unrun: production fe698597, test 35453146, manifest Git blob d225b99927f8ffb6e46db017befd31edb5c83141. All original before-images and unchanged quota/upload/queue dependencies join 3552 and are retained. It is separate from the existing N24 carrier 94fd763d. A later combined source map and selected-event receipt are required before promotion.

## Reuse and custody rule

Use each original raw receipt with its own native source/product tuple. Historical executable paths may now have explicit lossless custody receipts; an old path in evidence is not a current physical-execution grant. Current84a remains a separate protected product. Do not restore roles, mint invitations, reattach files, replace IDs, reopen old controllers with relaxed guards, or re-run passing cohorts merely to produce a newer timestamp. New execution must address a concrete missing or changed boundary.
