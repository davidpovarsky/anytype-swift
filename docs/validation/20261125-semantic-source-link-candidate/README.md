# Semantic text sources: candidate awaiting Apple qualification

This checkpoint adds source associations addressed to the real semantic marker in
both engines. It is not an E completion or a new acceptance result. The accepted
Heart mounted run 45536229185 and the original Any native/UI receipts remain bound
to their original source and products.

## Product behavior

The shared Torah session has a semantic target that uses the existing canonical
metadata codec, original object/space identity and immutable anchor UUID. Both
engines use the same source session, provider, search presenter, final write
authorization, canonical readback comparison and localized source actions.

Opening sources performs a new authorized document read without capture,
publication, selection mutation or metadata writes. Linking resolves again before
the canonical write and after its independent readback. Every serialized source
field and the marker identity must survive the canonical read. Missing, foreign,
ambiguous or retired targets cannot fall back to a whole-document source. A
possibly committed but unconfirmed link is reported uncertain and is not retried.

Removal rechecks the current action, document lifetime and edit authority at the
repository's final write boundary. The full canonical records must prove absence;
a change of metadata cannot pretend that an association was removed. Existing text,
other source associations and the native marker remain intact.

The Heart adapter reads the existing authorized ObjectShow with its original
account/space lease. It validates the actual root, exact owner details, native child
order, complete reachability, unique byte identities and text marks. It exports no
new Go symbol. The Any adapter reads its real native editor document without
publishing a display read or changing focus. The shared UIKit range inspector
recognizes a complete selection of one canonical marker in the current document.

## Review performed
