# Captured Pinkha schema and canonical source adapter

This checkpoint connects the original captured Pinkha schema manifest to source
hierarchy roles and the actual native property that contains canonical Torah
associations. It is a component qualification. It does not grant destination
write authority or prove a complete space migration.

## Product behavior

`AnyHeartNativePinkhaSource.discover(in:)` accepts the verified native outer
bundle. It finds the original manifest using its native object identity and
source-space binding, then resolves all property and type roles against captured
native definition IDs and keys. Display names cannot select a property. An
ambiguous, foreign, future or incompletely provisioned manifest is not accepted.

The adapter retains the complete manifest bytes, original protobuf and JSON
snapshot bindings, hierarchy parent/order representations, default template
identities and unknown manifest fields. Missing parents, cycles, unsupported
parent roles and the distinct book-folder behavior remain explicit requirements.
It does not flatten those entries or substitute a page for another layout.

Canonical associations come from the exact captured property key selected by the
manifest. An absent property and an explicit empty string remain distinct.
Nonempty canonical bytes pass the shared codec, duplicate/numeric JSON guard,
exact owner checks, source block existence and stable/semantic identity checks.
The component plan then uses the qualified semantic migration path from e49e59c,
preserving association and anchor identities while remapping both owner IDs.
The actual native destination marker check remains necessary before completion.

The shared capture review now retains this schema result or its specific binding
error and displays counts for actual hierarchy entries and source associations.
It continues to return `permitsDestinationWrites == false`. The new SwiftUI
section has a syntax check and awaits the next affected Apple build; it is not
part of the frozen ca7/8aa actual UI continuation.
