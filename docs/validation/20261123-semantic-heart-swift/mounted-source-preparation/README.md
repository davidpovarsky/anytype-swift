# Mounted source preparation, not execution

The separate fixture, observer and real XCUI journey are authored and passed
Swift syntax parsing only. No UIKit typecheck, native preparation, UI method or
Apple cold reopen has executed. source-plan.json pins the candidate sources.

An independent read-only review matched successful local account/Space creation,
private seed readback, explicit-empty Restrictions and actual native BlockCreate /
ObjectShow fields to the boundary consumer. It identified the missing error-path
cleanup in the first draft. The final preparation now closes any owned document,
stops a created account and shuts down the native app on failure while rethrowing
the original error. Initial and final syntax-only receipts are preserved.

The observer only watches real product callbacks; the UI test performs native
touches and presses the actual confirmation actions. Its full mounted proof
requires the separately built and admitted Mac products and actual execution.

The existing UI-only Xcode project uses explicit PBX source references. A source
inventory review found the new UI file needed those references; the follow-up
adds its standard build file, file reference, Tests group member and Sources
member. The existing ui_only_project generator inherits all four entries. The
main App/AnytypeTests synchronized roots are unchanged. This inventory fix is
not an Apple compile or execution receipt.
