This source tranche connects the already published bounded save-message plan, original Markdown parser and durable aggregate state to Any's original native conditional Markdown primitive. It adds three package source files and five pure fixture methods, and extends the owned readback helper with optional normalized-body receipt fields. It does not add a production save binding, native engine implementation, persistence store, consent flow, cancellation engine, package pin or project configuration.

## Native execution contract

The original native binding presents the complete native confirmation and rechecks its original destination before entering the shared runner. Before any effect, that runner reserves the generic invocation identity and the full bounded aggregate metadata budget, rechecks its cancellation/deadline fence, then consumes the exact one-use approval. Original request identity is never regenerated for a partial or uncertain result.

The operation requires an untouched initial aggregate. One original `AnyApplicationSession.perform` lease owns the entire worker lifetime. Before every new root or body effect it checks the original live UI/session authority, exact account and Space, native generation/run, unchanged native Page eligibility, shared cancellation/deadline fence and durable closed-dispatch flag. Read-only continuation uses the original native authority and may bypass only the model deadline; it cannot select another account or revive a revoked scene. Original native workers drain before their session can be replaced.

The original journaled page creator records the actual created root ID in the aggregate and original known-incomplete sidecar before subsequent reads or body dispatch. Creation remains separate from the native body operation; there is no create-with-body atomicity claim. Failure never searches by title or creates a replacement page.

The worker reads the original page through the original bracketed `AnyEditorDocumentStore` and requires the exact root title, zero body rows, no unreachable rows and empty native Markdown. A fresh original Markdown GET must agree on the opaque native version. It then durably records one atomic body dispatch and issues exactly one original conditional PUT using that version. An obsolete version has no unconditional fallback. The stable host request correlation is not native deduplication.

The complete actual ACK is persisted before later body verification. An acknowledged response whose readback became unavailable or changed still retains its original IDs and receipt metadata. An ACK outside this consumer's strict 64-ID bound stays unresolved; its full bounded fingerprint is retained without truncation, and no final save result is emitted. A lost or malformed ACK cannot be inferred from matching current text.

Success requires the actual same-version normalized Markdown bytes, the original full native snapshot and root record, exact native block order/identity and the expected complete semantic body. The final bracketed original Markdown read must still match the acknowledged version and content digest. Only after the original protected journal durably records `bodyVerified` may the shared runner receive the final root and decide whether the caller is still eligible to receive output.

Cancellation and authority loss close dispatch before another effect. Already dispatched work may retain late receipts in its original namespace; receipt persistence does not grant read or write authority. No cleanup deletes the partial original page, and no automatic retry is performed.

## Supported content and limits

The consumer accepts at most 512 UTF-8 title bytes, 65,536 raw Markdown bytes and 64 supported semantic blocks. The original completed Hanlin parser supplies the AST. Unsupported or lossy structures are refused during pure conversion before native effects. Native Markdown may normalize syntax; the requested digest and normalized actual digest are separate. Full text, Unicode bytes, style, link, hierarchy and order semantics must survive the native readback. Native output is independently bounded by the qualified original 262,144-byte primitive.

The new-page contract admits only actual inserted body IDs, with no updated/deleted IDs and zero unchanged body rows. A native shape outside that contract is retained as an incomplete original object, never reported as a complete saved message.

## Authored tests and required acceptance

The five new methods cover original parser/raw-byte binding, exact request/page/version/native-generation correlation, full native ACK context and groups, over-limit ACK fingerprint preservation, and normalized native bytes with complete semantic/ACK identity. They invoke the production pure helpers and original parser with native-value fixtures. **All five are NOT_RUN.** The inherited state/parser/Heart fixtures and this tranche are source-only until an actual compiler and test runner execute them.

Source membership uses the existing package target directory and the existing synchronized `AnytypeTests` hosted-test group. The shared producer must bind these actual source paths to the real compiler FileLists and enumerate the real methods. A filename in the repository is not compilation or test execution.

Before production registration, acceptance must execute the real DEBUG-only native save binding through the original SDK presentation-tool path and visible native consent in both engines. It must retain the actual invocation, root ID, original ACK and body receipt, and cover supported Hebrew/English formatting, cancel before dispatch, cancel after root/body dispatch, loss of readback, concurrent edit/CAS conflict, account or engine replacement while pending, no duplicate root/body write, and original-account drain. Original known-incomplete/uncertain results must remain distinguishable from full success. No existing engine-only receipt, pure fixture or old App Debug acceptance may substitute for those results.
