Logs in this directory contain test outcomes and hashes, not account credentials or captured content. Private accounts, canonical payloads, runtime account/space bindings, prepared journal, raw native logs and cold readback remain at the original protected evidence locations shown in the receipt; they are deliberately not copied into Git.

The native input is an explicit immutable component fixture. It is not a source-authorized Heart capture, and its successful content comparison does not grant whole-source admission. The real 156-source blockers (unsupported derived semantics, layouts/actions, source context roots, settings/ACL/history and remaining source adapters) remain explicit. No original file-P2P, default, T2, E or UI proof is relabeled by this checkpoint.

The frozen controllers preserve their actual retained paths and source identities. They are evidence of these executions, not a general-purpose replay launcher for a different account.
