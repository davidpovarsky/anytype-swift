The new pure `TorahLegacyAssociationCutoverPlan` uses the production shared Swift codec to preserve the original property presence, key and bytes, every source record, unknown envelope/record/item fields, exact numeric identity, record location and semantic marker owner. It refuses partial, duplicate or unrepresentable input. It performs no reads or writes to an engine.

`ValidateSourceCoverage` independently checks the resulting native plan against the complete original legacy bytes. It is a verifier, not a replacement JSON encoder. Only the existing codec’s explicit v1 lift, optional-known-null representation, role spelling and lossless date normalization are recognized. Missing/extra facts, foreign owners, unknown-field loss, imprecise numbers, malformed Unicode, changed semantic owners and future reserved metadata versions are refused.
