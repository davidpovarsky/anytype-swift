# Native continuation dependency-lock repair

The original Any run 45057855584 built the app and runner, then refused Xcode's untracked NativeApp Package.resolved before any of its nine selected UI journeys ran. The original failure and build-product manifest are copied unchanged here. The 37,567,358-byte original artifact remains on GitHub (14768344831); this directory does not duplicate its app binaries.

The new controller accepts only the one originally observed generated path and exactly the dependency pins already published in Modules/PinkhaAnyUI/Package.resolved. It rejects changed revisions/locations, missing/additional pins, duplicate keys/identities, symlinks, stale evidence, tracked edits and unrelated untracked sources. It preserves the original generated bytes, their original hash and originHash, and the canonical lock before removing that one reproducible output. The original clean-source guard is unchanged and must then pass.

Continuation execution uses the original compiled xctestrun for the six failed journeys, Files, Custom Type and History. This prevents a second project resolution from regenerating the lock after the clean-source/product freeze. Full/older routes retain their previous project invocation. Exact app/runner/native binding and source admission remain mandatory.

Six new real-filesystem methods passed on Oracle; original log and source hashes are in controller-receipt.json. YAML parsed and all five changed shell steps passed bash syntax checks. No Apple execution or application acceptance is claimed by these controls. Existing accepted tests were not rerun. SDK and Release changes are independently owned and integrated separately.
