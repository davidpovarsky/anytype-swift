# Original catalog and historical metadata: qualified engine adapters

This ordinary commit adds two Host adapters and the exact public qualification material. Its parent is `e6fedfdbc7390a5a4e934726806c952319ba4238`. Wave 3 owns integration into the final App branch.

## Product behavior

`AnyNativeImportedCatalogDirectory` reconstructs the complete original catalog addresses from the saved migration plan and its receipt-bound mappings. It validates coverage, exact UTF-8 source identities, the immutable intents, native record identities and source capture hashes. A catalog carrier address is never treated as the destination identity of an editable Type or property.

`AnyNativeImportedCatalogStore` reads each current native row under the existing account/Space/session lease and current signed membership, validates its original prepared intent and signed creation, and compares before/after receipts and rows. It returns the exact captured protobuf/JSON evidence and original tree JSON. A head without a captured snapshot remains explicit.

`AnyHeartOriginalMetadataStore` separately binds the original definition and requested original object to that same catalog. Its eleven closed roles are addedDate, createdInContext, globalName, importType, internalFlags, oldAnytypeID, origin, revision, sourceObject, timestamp and uniqueKey. Missing values remain distinct from present null, false, zero, empty strings and empty arrays. These are historical values; they do not replace current native system attributes or grant writes.

The production changes are additive modules. They do not modify UI files, native routes, account data, the final integration branch or the existing Type25 providers.

## Acceptance boundaries

This proves the catalog/metadata component and actual signed native read/reopen scope. It does not reconstruct the original encrypted history, change historical authors into destination signers, provide whole-Space functional migration, qualify every property/layout family, prove cloud durability, or establish mounted App/Apple adoption. The original182 migration operations are retained evidence and were not replayed. The separate Home/last-opened navigation cohort and native bound routes will be handed off independently after their pending qualifications.
