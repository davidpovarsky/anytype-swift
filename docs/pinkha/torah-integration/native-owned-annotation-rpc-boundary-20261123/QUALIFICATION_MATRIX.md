# Proposed native RPC qualification, after source approval

This is a new boundary matrix, not a request to replay the nine-leaf B1/C gate or any historical36 cases. Actual cases, generated selectors and a single source-bound producer must be reviewed after the current native result. No row below has run.

| Boundary | Genuine witness | Required observation |
| --- | --- | --- |
| Generated original dispatch | Real generated handler and actual Middleware/application with a new disposable same-account source graph | One real owned import; actual Done before returned response; full source mapping, body ZIP/report and errors copied from Result |
| Cancellation after registration | Actual existing ownedAccountImport/token and original RequestCancel, without a substitute executor | Cancel resolves only that real owner, actual canceled native return/drain occurs, raw response history remains copied before original Invocation completion |
| Cancel before registration | Same closed SDK attempt with a real in-flight original call, actual lookup before entry is admitted | NOT_OBSERVED does not complete the owner or authorize a new import; the original call remains owned through actual response/drain |
| Wrong attempt or source | Independently wrong token/account/Space/digest against an actually active owned operation | No matching original RequestCancel invocation; real operation outcome is not manufactured or replaced |
| In-flight duplicate attempt | Same admitted actual token through the original application owner | A second execution is refused; this does not claim durable replay protection after pruning/process restart |
| Original error or partial readback | Actual native refusal/cancellation/observer failure retained from the owning operation | Native error and observed readback stage remain distinct; a populated body or nil wrapper error cannot mint ACK |
| Account/source retirement | Original retirement requests cancellation while real native operation owns its app/lease | No app/data release from a Cancel response or lookup miss; only actual Done and original invocation drain allow the existing owner to progress |
| Copy overflow | Actual immutable complete outcome measured against the reviewed concrete wire budget | Explicit copy refusal; no truncated archive/graph/file list, no automatic reimport or successful body acknowledgement |

Source controls can check the exact finite error projection, field counts and private per-command logging masks if their implementation creates concrete risks. They are not native execution evidence. Expected double-based controls must be labeled as such.

The current accepted archive/lifetime/schema/RPC generation receipts remain tied to their original source and scope. A future RPC gate may use fresh genuine source exports as necessary disposable inputs; those are not old selector replays or additional credit for historical tests.

## Implementation decisions still requiring the root/SDK join

1. Prove a closed attempt is constructed only from actual account/selected-Space/source captures and that its cancellation secret cannot be supplied through a public SDK owner constructor.
2. Specify the finite cancellation observation window, same-owner rejoin and replacement-blocked state when a pre-admission lookup misses. No wait budget can become a drain receipt.
3. Use the genuine nine-leaf result to finalize complete wire-copy bounds; preserve existing archive/Host policy separately.
4. Qualify the real original Swift completion/history path and the exact Host saved revision before any mapping/ACK. Local saves with zero outbox deliveries require their own actual persistence join, never a fabricated delivery.
