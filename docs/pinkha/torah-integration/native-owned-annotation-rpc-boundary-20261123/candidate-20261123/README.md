# Original Annotation Import RPC source draft

This packet prepares five native product afterimages and two focused boundary-test sources. It has not been generated, compiled, linked, dispatched or qualified natively. The running Native9 qualification is a separate, frozen source tree.

## Original ownership

The application record gains one optional immutable cancellation comparison. The existing Service, account lease and owned-import registry remain the owners. The generic import admission implementation is otherwise byte-identical after the additive field is removed. The annotation private nil-binding route delegates to the same original admission body; the exact inverse proof restores its original source.

One blocking Import captures the actual application, rechecks the same original wallet/lease under the original read lock, prepares the native-owned archive and inserts the original operation before Start. All native execution and waiting occur after both locks are released. Caller context cancellation requests the original cancellation and then still joins the actual Done. The same call copies Result and removes only its now-drained registry entry; no retained result cache or alternate executor is introduced.

Cancel compares the complete private tuple against an existing record, releases the registry lock and requests the original cancellation. It can neither start an import nor release an owner. It intentionally does not acquire fresh selected-Space write permission to locate historical work. NOT_OBSERVED is not evidence of no work, no startup, drain or retry authority.

## Same-owner Swift agreement

The SDK source owner read the actual withUncancellableHandler and Invocation implementations. Swift waiter cancellation can return CancellationError without canceling Go. The actual native response is still synchronously observed before completion.finish; the original binding onDrained remains the historical completion boundary.

The proposed closed adapter retains one primary native invocation and the private cancellation tuple before invoking. It sends one cancellation-only request, then at most one second request after an actual NOT_OBSERVED response while primary history/drain remains pending. Two misses remain unresolved on the same owner. All cancellation returns/drains and the primary nativeResponseObservation/onDrained must join before release. No generated Swift implementation or acceptance is implied by this agreement.

## Request versus result policy

WIRE_POLICY_PROPOSAL.json distinguishes input validation from the post-native complete-response policy. The existing 1MiB native archive policy is retained. The new complete encoded response limit is 2MiB; new string/container limits are explicit proposals, not claimed original bounds.

Original Result/getter copies remain unchanged. The new handler checks finite counts, UTF8 string sizes and exact protobuf wire size on those owned values before constructing new protobuf row arrays. The real generated proto.Size must equal the preflight count before external marshal. An over-limit response returns COPY_REFUSED with the actual finite registration/Done/error/cancellation facts; the whole outcome/mapping/readback body is omitted, never truncated. This leaves Host body/mapping uncertainty intact.

The private native staging ArchivePath is deliberately omitted; each source assignment instead carries the exact already-validated source archive digest plus original member/source/converter/native fields. Original ExportReport content is copied exactly if admitted. The actual empty NoProgress process ID remains empty.

## Qualification boundary

The new test sources are transport/negative-admission controls only, not fake native execution. They use the future original generated protobuf encoder as the independent byte-size oracle, including exact2MiB and one-byte-over messages. Empty-Service cancellation misses cannot prove original import cancellation/drain. Genuine generated dispatch, actual app/account/Space, pre-registration cancellation, late history, real mapping/body and actual native cleanup still require separate reviewed qualification.

No generated output was handwritten. The actual original commands/service generator inputs are preserved, with only the new nested Import/Cancel definitions and two service declarations appended. Existing schema registration and all B1/C import engine files are unchanged.

Native C/gRPC request/response logging and Swift per-command masking must be source-reviewed before activation because archive bytes and the private cancellation secret are sensitive. Logging review is pending in this draft; no route has been activated.

There is no public ACK, fresh current-permission receipt, cold reopen, durable mapping or automatic retry claim. The Host must independently join the real saved row/body/revision and actual original captured owner after native Done. Local rich-body saves still produce zero outbox deliveries; no synthetic outbox row may be introduced to reuse an unrelated delivery fence.
