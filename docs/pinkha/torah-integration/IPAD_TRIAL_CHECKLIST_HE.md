# רשימת בדיקה — ניסוי Torah Inspector ב‑iPadOS 27

> אזהרה: פעולות כתיבה מיועדות רק ל‑Space חדש וחד־פעמי ולמסמך חדש וריק.
> אין להפעיל אותן במסמכים קיימים או במידע בעל ערך. מצב זה תומך במכשיר כותב
> פעיל אחד בלבד ואינו הוכחה לסנכרון T2 רב־מכשירי.

## התקנה וכניסה

- [ ] חתום והתקן את ה‑IPA הניסיוני בעזרת תהליך sideload מתאים. ה‑IPA שמופק ב‑CI אינו חתום ואינו מותקן ישירות.
- [ ] ודא שהאפליקציה נקראת `Anytype Torah Trial` ושמזהה החבילה הוא `com.gloiiire.anytype.torahtrial` — אין להחליף את אפליקציית Anytype הרגילה.
- [ ] בצע כניסה רגילה בתוך אפליקציית הניסוי. ה‑sandbox הנפרד אינו משתף אוטומטית session או נתונים עם האפליקציה הרגילה.
- [ ] בעת חתימה/סידלואד השתמש ב‑Bundle ID `com.gloiiire.anytype.torahtrial` ואל תעניק את קבוצת האפליקציה הרגילה `group.io.anytype.app`; ה‑IPA נבנה ללא entitlements וללא extensions.

## קריאה ו‑Side Sheet — ללא כתיבה

- [ ] פתח מסמך ולחץ על `תורה / מקורות` בפינה הימנית העליונה.
- [ ] בחר `מקורות`, חפש `בראשית א:א`, ולחץ `פתח במפקח`.
- [ ] ודא שה‑Side Sheet הילידי מופיע בצד הפיזי הימני גם בממשק עברי RTL.
- [ ] בדוק שלושה מצבים: Peek בגובה 155, בינוני ומלא; אין חיתוך או איפוס ניווט.
- [ ] פתח את פרטי הפסוק, `פרשנים`, `קישורים` ו‑`הערות`; עבור לפרק קודם/הבא וחזור.
- [ ] סגור ופתח מחדש את הגיליון, והמשך להקליד במסמך הראשי.
- [ ] כבה רשת ובדוק שהשגיאה גלויה ואינה מוצגת כתוכן או שמירה מוצלחים.

## כתיבה ניסיונית — רק יעד חד־פעמי

- [ ] צור Space חדש שמיועד למחיקה וניסוי בלבד, ואז מסמך חדש וריק.
- [ ] פתח `תורה / מקורות`, אשר `זהו Space חד־פעמי חדש` ו‑`זהו מסמך חדש וריק`, הקלד `DISPOSABLE`, ולחץ `הפעל כתיבה ניסיונית`.
- [ ] קשר מקור, נושא ומילה למסמך; ודא שמופיעים תחת `קשר תורני במסמך`.
- [ ] לחץ לחיצה ארוכה על בלוק יחיד, בחר `קשר תורני`, הוסף קשר ובטל קשר יחיד בלי לפגוע באחרים.
- [ ] ודא שהמצבים `ממתין`, `שומר`, `נשמר ואומת`, `לא ודאי`, `התנגשות` או `שגיאה` מוצגים בכנות.

## ציטוט, גרירה והערות

- [ ] בפסוק לחץ `הוסף למסמך`; ודא שנוצר בלוק quote אמיתי באותו מסמך ושמקלדת/פוקוס לא קופצים אליו.
- [ ] הוסף אחר כך בלוק רגיל וודא שהתנהגות הפוקוס הרגילה לא השתנתה.
- [ ] גרור מקור מה‑Side Sheet אל העורך. אם המערכת אינה מאפשרת גרירה מהגיליון הילידי, רשום זאת כ‑`USER TEST PENDING/PLATFORM LIMITATION` וודא שכפתור ההוספה עדיין עובד.
- [ ] ודא שגרירת בלוקים פנימית עדיין מבצעת move ולא copy.
- [ ] בלשונית `הערות` צור הערה, פתח את מסמך ה‑Note האמיתי, חזור ובטל את הקשר. ודא שמסמך ההערה עצמו לא נמחק.

## עמידות ופלטפורמה

- [ ] סגור בכוח והפעל מחדש; בדוק קריאה, קשרים והסרת קשר. סמן **USER TEST PENDING** עד שבוצע בפועל.
- [ ] בדוק מצב offline לאחר תוכן שכבר נטען; אל תסמן PASS אם ספק Sefaria או הכתיבה דורשים רשת.
- [ ] בדוק Undo/Redo אחרי הכנסת quote, מחיקת בלוק, מעבר מסמך ושני חלונות. תעד כל פער בלי retry עיוור.
- [ ] אין בדיקת text-span עמידה בגרסה זו; אל תפרש קשר בלוק כקשר לבחירת תווים מדויקת.
