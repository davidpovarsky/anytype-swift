# רשימת בדיקה — עדכון Anytype Torah ב‑iPad

> שם הקובץ נשמר לצורך קישורים היסטוריים. זוהי בדיקת **עדכון במקום**, לא
> ניסוי שמצריך מחיקת נתונים. אין להסיר את האפליקציה הקיימת ואין לאפס חשבון.

## חתימה והתקנה כעדכון

- [ ] שמור את `Anytype Torah Trial` המותקנת ואת הנתונים שלה; אל תבצע Uninstall.
- [ ] חתום את ה‑IPA החדש באותה זהות/Team ששימשו להתקנה הקודמת ובאותו Bundle ID:
  `com.gloiiire.anytype.torahtrial`.
- [ ] אל תוסיף את קבוצת הייצור `group.io.anytype.app`, entitlement של ייצור או extension.
- [ ] התקן מעל האפליקציה הקיימת. שם התצוגה החדש יכול להיות `Anytype Torah`;
  שינוי השם אינו שינוי sandbox.
- [ ] פתח את האפליקציה וודא שהחשבון והקשרים הקודמים נשמרו. אם iOS מציע למחוק
  קודם, עצור — החתימה או מזהה החבילה אינם תואמים.

## קשרי מסמך ובלוק — ללא שער ניסוי

- [ ] פתח את המסמך שבו כבר נשמר קשר בלוק. ודא שהוא עדיין מופיע.
- [ ] לחץ `תורה / מקורות` בסרגל העליון. ודא שהכותרת היא `קישורים במסמך`
  ושאין שדה `DISPOSABLE`, מתגים או הפעלת כתיבה ניסיונית.
- [ ] הוסף למסמך מקור, נושא ומילה; סגור ופתח שוב את החלונית ובדוק שהם מופיעים
  רק בהקשר המסמך.
- [ ] לחץ לחיצה ארוכה על בלוק ובחר `הוסף קשר תורני`; ודא שהכותרת היא
  `קישורים בבלוק` ושהפעולה אומרת `קשר לבלוק`.
- [ ] הוסף קשר בשני בלוקים שונים, הסר קשר מסמך אחד ובדוק שקשרי הבלוקים לא השתנו.
- [ ] סגור בכוח את האפליקציה, פתח מחדש ובדוק בנפרד קשרי מסמך וקשרי בלוק.
  עד לביצוע בפועל תוצאה זו נשארת **DEVICE PENDING**.

## פתיחת המקור בגיליון המערכת

- [ ] לחץ פעם אחת על תג הספר הקטן בצד בלוק מקושר. במקור יחיד צריך להיפתח מיד
  ה‑Side Sheet האמיתי בצד הפיזי הימני, בלי לעבור דרך חיפוש.
- [ ] ודא שהפסוק המדויק נבחר ושמופיעים קשרים/פרשנים; בדוק Peek ‏155,
  Medium ו‑Large.
- [ ] בבלוק עם יותר מקשר אחד ודא שמופיע בורר עם שמות ברורים, ואז פתח כל מקור.
- [ ] בנושא או מילה ודא שלא נפתח פסוק שגוי; צריך להופיע הבורר המוקלד.
- [ ] לחץ בתוך טקסט רגיל, לחץ פעמיים על מילה, גרור לבחירה ולחץ לחיצה ארוכה.
  העריכה והבחירה חייבות להישאר רגילות; אין מחוות כפולות כלליות על הטקסט.

## עברית, אנגלית וציטוטים

- [ ] בעברית בדוק שהתג וה‑Inspector מציגים `בראשית א׳:א׳`, וששמות ספרים,
  מפרשים, נושאים, פעולות ושגיאות מופיעים בעברית כאשר לספק יש שם אמין.
- [ ] שנה את שפת האפליקציה ל‑English ובדוק שאותו קשר בדיוק מציג
  `Genesis 1:1`; חזור לעברית ובדוק שלא נוצר קשר חדש ולא השתנה מזהה המקור.
- [ ] הכנס ציטוט חדש. ודא שגוף ה‑quote מכיל את טקסט המקור בלי סיומת שפה קפואה,
  שהתג מציג את המקור בשפה הפעילה ושלא נכפה פוקוס עריכה.
- [ ] בדוק quote ישן שנערך בעבר: הטקסט הקיים שלו חייב להישאר ללא שינוי.

## Notes, הרשאות ומצבי קצה

- [ ] צור, פתח ובטל קשר ל‑Note בלי הפעלה מוקדמת; ביטול הקשר אינו מוחק את מסמך ה‑Note.
- [ ] בדוק מסמך לקריאה בלבד: הכתיבה/גרירה צריכות להידחות כשאין הרשאה אמיתית.
- [ ] בדוק offline ושגיאת ספק: אין להציג `נשמר` בלי readback ואין לבצע retry עיוור.
- [ ] בדוק Portrait, Landscape, חלון Stage Manager צר, מקלדת פתוחה, VoiceOver
  ושני חלונות אם אפשר. תעד PASS/FAIL בפועל; אל תסיק תוצאת מכשיר מ‑CI.

מגבלת סנכרון: המימוש שומר על תור כתיבה מקומי ו‑readback, אך אינו הוכחה למיזוג
בטוח של שני מכשירים שכותבים בו־זמנית. מגבלה זו אינה שער משתמש ואינה סיבה למחיקת נתונים.
