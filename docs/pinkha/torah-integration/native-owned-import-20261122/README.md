# Own original import upload and worker completion

This proposal contains fifteen original Heart source afterimages: seven changes to existing files and eight additions. Every existing preimage matches the actual Go1.26.5 original-module compile run 45047489968. Installation requires the original d984 Heart plus its exact r14 patch and the compatible diagnostic source overlay at 13f63c2d. The old five-field import request, default constructor, original ID/fallback behavior and r14 remapping remain intact.

An explicitly owned upload now retains the actual original asynchronous result channel. Its context reaches the original upload and final object lookup; cancellation requests do not close its Done signal. The ordinary UploadAsync still uses its original service context. A started handle survives an initial native Apply error and remains held until the real upload callback returns and its channel closes.

The private owned importer creates fresh converter/provider dependencies, registers file slots before native admission, drains original worker and submission channels on success, cancellation or first error, and then joins every admitted synchronous call and asynchronous upload. It rejects shared preloads, an unreviewed synchronous editor route and a live bookmark that needs an unjoined fetch. Its scoped provider observes upload failures that the original file providers intentionally log before returning a fallback ID; the original fallback side effects are unchanged. The owned finalizer does not clear component-wide remote-backup event queues.

Twenty-six new unit controls compiled and executed once with actual Go1.25.6 Windows: 26 PASS, no fail or skip. They compile exact candidate files/fragments, original WorkerPool/task/addWork and declared component ABI/callback fixtures. Both package compile checks completed before the first test. The first earlier uploader compile timed out at its 90-second bound with no diagnostic or test execution; that raw receipt is retained. A single explicit continuation added compiler tracing and a 180-second compile cap without changing the product or any assertion. No old 50/7 suites ran again.

The unit closure does not compile the complete new dependency constructor, block/editor hooks or importer.Execute. Full original-module compilation is the next separate gate. These controls establish drain of already-running original workers; the original select can still execute queued work after Stop. They do not promise that cancellation prevents subsequent writes or has bounded native latency. Original SmartBlock locking is not context-aware, URL error paths can retain original resources, and final block-update errors remain logged by the original uploader. Actual native semantic readback is still required.

There is no production callsite, generated RPC, account-lifetime admission or ACK in this packet. Its operation-local cancellation must be released by a future actual owner only after Execute and its historical mapping copyout return. Lifecycle retirement, exact account/Space/archive/attempt binding, complete native mapping/file evidence and authentic persisted-body comparison remain explicit downstream dependencies.
