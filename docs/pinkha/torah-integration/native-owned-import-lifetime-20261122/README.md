## Limits retained

The outcome is copied historical execution data, not archive/Space permission, stable semantic-body equality, complete mapping or ACK authority. The requested Space is a copied declared destination. Actual native membership/archive/attempt admission and a real cancellation-capable RPC still need their own route. Existing generated gomobile handlers use `context.Background()`; Swift task cancellation alone does not provide that native cancel handle.

Original non-context-aware SmartBlock locking can delay cancellation. The existing native worker select can execute queued work after Stop. Original remote file backup queues, URL-error resource cleanup and logged-only final update errors remain outside this local drain proof. This registry protects the reviewed explicit lifecycle paths; it does not promise component health or prevent unrelated native failure or parent-context cancellation. A pending lifecycle request requires a later retry; no success or automatic retry is fabricated.
