## Implemented boundary

The actual original Invocation prepares an existing owner's permit after asynchronous setup and rechecks it synchronously immediately before its unchanged native GCD body. Actual native completion, including a native error response, completes the same original operation. Caller cancellation does not mean that native work completed. Account transitions invalidate admission before their first await and wait for old native operations to drain before their original account RPC. Existing unbound calls retain their original route.

The same Owner synchronously reserves UI writes before Task construction. It retains every reservation, registered descendant and native RPC until actual completion. A source-bound child registers passive tracking leases in the same parent Owner; those leases do not authorize any parent-document RPC. Opening a child uses the captured source/account generations and retains its parent tracking through actual native drain. A read operation cannot promote itself into a mutation or a wider RPC allowlist.

Exclusive capture refuses fresh UI writes, drains registered work, checks sticky edit failures, executes the declared original export/read operations, and validates ownership and failures again. When `retireOnSuccess` is selected, retirement occurs inside the exclusive gate before it is released. A canceled export retains the gate while a real native body remains active. `isCapturing` lets Host recovery avoid restoring interaction before that drain. An abandoned unstarted reservation fails closed; a native or synchronous preparation error cannot become a successful capture merely because an original UI closure catches it.

Original ObjectActions and Pasteboard routes delegate to their existing services. Bound paste reserves synchronously before Task creation and keeps its actual MainActor completion within the registered operation. Original NSItemProvider and PasteboardTask paths reuse the shared session-owned retained staging; they do not add a recovery directory or delete files needed by an uncancellable native operation. Exact prepared document instances, object IDs and Space IDs are checked. Existing nil/unbound paths are preserved.

Original BaseDocument retains its initial frozen account-only dispatch context for subscription construction and eventual original close, including detached deinit. Reopening a cached document revalidates that captured context rather than recapturing a new account generation. Existing event subscribers capture account-only committed-event authority at construction and reapply it at delivery. This is RPC/account qualification, not a claim that every downstream UIKit/store effect is qualified.
