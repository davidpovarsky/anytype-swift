# Discriminating qualification plan

All cases are proposed and **NOT_RUN** here. Accepted historical tests are reused only within their exact source/evidence boundaries. No full test-suite replay is requested.

## Gate A: actual archive and graph evidence

Use the existing original LocalOnly disposable wallet/account/regular Space fixture and original annotation registrar. Create actual annotation content through original native APIs and export it with the same original ObjectListExport flags used by the Host: protobuf, ZIP, includeFiles/nested/archived, no backlinks, no Space, no progress, no state filters.

Retain the genuine ZIP, ExportReport protobuf, exact source/execution identities and a decoded inventory of every native member/type/reference/file source. The content should exercise mixed Hebrew/English text, formatting, nested references and one real owned attachment in separate independently reported specimens. The attachment specimen is inventory evidence, not acceptance of the proposed file write path. Do not hand-build a ZIP and label it an original export.

Validate the actual exported bytes through the new native admission constructor. Derive rejected variants from that bounded genuine source for only the relevant missing/extra binary, unsafe/ambiguous name, duplicate map key, malformed CRC/framing and unsupported-field cases. Retain the specific failing reason and proof that no original import was started. Do not rerun unrelated Python/Swift archive fixtures.

## Gate B: actual assignment and create semantics

| Case | Genuine action and required distinction |
| --- | --- |
| Full admitted graph | Run original converter/ID assignment/creator through the closed operation. Require every admitted member to receive exactly the reviewed disposition and complete actual mapping. No unaccounted root collection. |
| Root collision | Create the actual target root alias in a disposable existing Space, then attempt import. Reject before any import write. |
| Non-root collision | Create a genuine nested-member oldAnytypeID or uniqueKey collision while the root remains absent. Whole-graph admission must reject before any earlier file upload/schema/body effect. |
| Reused schema | Compare actual schema state and real tree heads before/after. A verified reuse must bypass the original creator and leave the existing object unchanged, including favorite/archive/sync effects. |
| Mismatched schema | Same name or key with different actual definition must reject; it cannot reset or auto-install the target definition. |
| Actual ErrTreeExists | Build an original payload, create that payload through the actual Space API, then exercise the strict original create boundary against the same real payload. It must retain the native collision and unchanged existing body; no injected collision error. |
| Unsupported member/reference | Reject workspace/widget/profile/participant/chat or unknown external reference before assignment/effects; verify real target heads/inventory unchanged. |
| Actual apply failure | Exercise a real native denial/failure at the supported apply path. A logged error or an existing-object read must not become a success result. |

Native no-mutation assertions must use actual object/tree/storage observations, not a caller-provided “no writes” boolean. The typed disposition itself is not runtime proof.

## Gate C: cancellation, lifetime and live permission

Reuse the original accepted prestart cancellation leaf only if the changed path remains provably unreachable there. Add focused new cases for admission-to-assignment cancellation, cancellation after a real apply, actual signed-ACL denial before first write, signed-ACL revocation before the next write and a reentrant original AccountStop during actual native work.

For each case distinguish: cancellation requested, real work entered, actual effects admitted, original Execute/finalizer returned, Done closed, copied Result available, and final actual AccountStop/lease release. Cancel RPC return is never drainage. A historical wire response remains observable after source retirement, but it cannot grant a new write.

Test native root creation separately from content apply. Do not infer atomic revocation semantics from a preflight ACL query. Use real signed original ACL transitions and the actual executing wallet identity.

## Gate D: body readback and resume

After actual original import completion, keep the same closed annotation operation registered while it uses the actual original exporter on the exact mapped graph. Done must remain open until that export/comparison and its original worker finalization have returned. Inspect the original ExportReport and cancellation state. Compare supported content under the proven source-to-native mapping; introduce one real body/reference/file change and require comparison failure. The same-ID comparator cannot serve as a fresh-ID oracle.

Then stop/drain and reopen the same real persisted account/Space/object through original lifecycle calls, without another import. Require a distinct process for the separate process-resume gate. Record live-object readback and cold/process reopen separately.

Unknown outcome after a process loss must not trigger an automatic fresh import. Show recovery of a known mapping, or retain an explicit unresolved result. Do not manufacture an ACK, source receipt, body digest or successful startup.

## Gate E: genuine generated end-to-end boundary

Only after the native contract is implemented and reviewed, run the original generator for the exact new proto delta. Reuse the accepted 45101449367 baseline where the exact inputs are unchanged. Compile actual generated Go dispatch, native endpoint, generated Swift methods and real Invocation; do not hand-write generated methods. Exercise Start/Observe/Cancel/Release through that actual native client boundary.

The original SDK owner composes the closed Host/account/selected-Space source. Production activation still requires actual saved-revision/source CAS, current permission, full body readback and the selected app acceptance gates. Native handle creation alone is not completion.
