# בדיקות iPad פיזי — Stage 1

כל הסעיפים כאן הם **NOT_RUN על מכשיר פיזי**. אין להסיק PASS מבנייה, Windows, בדיקות UIKit או סימולטור. יש לצרף דגם iPad, גרסת iPadOS, שפת האפליקציה והמערכת, SHA של ה־IPA ותוצאה לכל סעיף.

יש להשתמש רק ב־Space מקומי זמני ובמסמכי בדיקה. אין לבצע את הבדיקה ב־Spaces אישיים. זיהוי ה־IPA ותוצאות האוטומציה מופיעים בדוח [המימוש](STAGE_1_IMPLEMENTATION_2026-11-02.md); רשימה זו אינה אישור release או חתימה.

1. **הקלדה ומיקוד:** באפליקציה בעברית ובמערכת באנגלית, לפתוח Pinkha, Note ו־Page. לבדוק את הסמן הריק לפני הקלדה, להקליד תו עברי ראשון ולעבור לפחות חמש פעמים ב־Enter. הסמן והמיקוד צריכים להישאר בבלוק הנכון. לבדוק גם לחיצה בשורה זמנית תחתונה והקלדה ראשונה בה.
2. **מקלדות ו־IME:** לחזור עם מקלדת חומרה ועם מקלדת המסך; להחליף עברית/אנגלית באמצע המסמך. לבדוק טקסט מסומן/בתהליך composition, בחירה, העתקה/הדבקה ו־Undo/Redo. לא אמורים להיעלם טקסט או בחירה, להיווצר בלוקים עודפים או להופיע קריסת accessory view.
3. **פתיחה מחדש:** לסגור ולפתוח את המסמכים ואת האפליקציה. חמש השורות חייבות להישמר. לבדוק יישור מפורש לשמאל/מרכז/ימין, ואת מסלול האנגלית באפליקציה באנגלית כשהמערכת בעברית.
4. **מקורות:** לוודא Sources + / מקורות + בשורת metadata עם 0 קשרים; להוסיף 1, 2 ו־12 קשרי מסמך ולבדוק שני chips ו־+N, פתיחת Inspector, חיפוש והסרה. Tags ו־Page/סוג נשארים תקינים. אין כניסת ספר עליונה או ב־overflow בתוצר הסופי. פעולת מקור מסמך אינה יורשת בלוק פעיל או Space אחר; הרשאות קריאה בלבד נשמרות.
5. **תצוגה ונגישות:** לבדוק חלון צר, סיבוב, Stage Manager, שני חלונות בשפות/כיוונים שונים, Pointer ו־VoiceOver. רכיבי המקורות נשארים נגישים, ללא חיתוך או שורת metadata כפולה; פעולת חזרה רגילה ו־Inspector נשארות תקינות.
6. **תורה:** לבדוק קשר מסמך וקשר בלוק, ציטוט והערה, עוגן בחירת מילה וחיפוש בתוך Inspector. שינוי קשר מקור אינו מזיז מיקוד או גורם לטעינה מחדש של כל העורך; הכנסת ציטוט אינה מקבלת מיקוד אוטומטי חדש.

לכל FAIL יש לרשום פעולה מדויקת ותוצאה בפועל ולצרף צילום/וידאו ללא מידע אישי. אין לסמן שער מכשיר ב־Asana כהושלם ללא ראיה ובקשה מפורשת לעדכון.
