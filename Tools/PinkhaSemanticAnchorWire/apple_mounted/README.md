# Page154 actual mounted selection acceptance

This separate candidate prepares one synthetic native Page on a fresh owned
simulator, then runs one XCUI journey through ordinary cold App startup and the
normal anytype://object route. The actual UITextView receives native tap/double
tap gestures. XCTest presses the ordinary selection menu, Cancel, Create text
anchor and Done controls. It terminates and launches the App again, opens the
same native page and observes the persisted mark. Source preparation is not
mounted acceptance; all actual Apple execution remains NOT_RUN.

## Build and execution ownership

The separate Apple consumer builds the current App/AnytypeTests and a UI-only
PinkhaPrebuiltUI runner once, preserving both original Products trees and
xctestrun descriptors. Its boundary method is independent and is never rerun
by this mounted scope. source-plan.json contains the exact new selectors and
source hashes. Both candidate compile flags and the exact Page154 runtime
artifact are required. Default production139 stays unsupported.

The future mounted controller must admit the original source map, every archived
file/link, original descriptors, current framework hashes and both archive
digests before copying descriptors for the two exact selectors. It must use a
new owned simulator and report preparation and journey results separately.
A build-only runner receipt cannot be relabelled as execution.

## Actual assertions

The preparation creates a private LocalOnly account/Space, a native text block
with a preexisting bold mark and explicit-empty Restrictions, and a separate
unselected block. The selected word is deliberately one deterministic word;
Unicode range/byte controls retain their separate host/native evidence.
The fixture is bound to source SHA, CI run/attempt, nonce, account, Space, page,
both block IDs and original deterministic protobuf snapshots. Wallet recovery
material stays in the private App keychain/container and is never exported.

The DEBUG/simulator observer only reads the actual mounted editor, selection,
ordinary BaseDocument publication and resulting UITextView attributes. It
cannot select text, queue Apply, approve, navigate, swap Invocation's handler
or publish a reducer event. Its hooks are inactive without the explicit owned
fixture environment. It requires the real InvocationMesagesHandler, LocalOnly,
disabled middleware logging, the exact Page154 version and the current lease.

Cancel must leave both exact native blocks and the opened document unchanged,
with zero queued Apply and zero candidate document publication. The second
explicit confirmation must queue one Apply, produce one matching publication
in the actual BaseDocument, preserve the original text/non-mark block fields
and unselected block, and return a verified native change receipt. The observer
captures actual rendered link attributes and document marks before its own
independent ObjectShow readback.

Cold reopen requires a different App PID and lifetime generation, no new Apply,
the same exact persisted native block/receipt and the same rendered link. The
XCUI runner retains screenshots and both structured observations. A controller
must independently compare the on-disk capture and reopen receipts, including
the exact capture-receipt SHA-256 carried by the reopen observation.

## Limits

This is an opt-in simulator diagnostic, not a shipping surface or an alternate
product path. It does not extend the native fixture's explicit-empty Restrictions
guarantee, add reserved-link navigation, cover arbitrary views or physical
hardware, or establish full migration acceptance. The qualified 19 host methods
and 11 retained Wire methods are not rerun for this source-only App addition.

## Run without rebuilding

The controller requires a committed admission JSON, prepared from the completed
original App consumer API/artifact metadata. Its exact keys are consumer_run,
consumer_attempt, consumer_sha, artifact_id, artifact_bytes, artifact_sha256,
native_manifest_sha256, ui_manifest_sha256, native_descriptor and ui_descriptor.
The manifest fields pin the original App Products and UI Products manifest
files. Each descriptor object has exactly sha256 and main_thread_checker_token:
the exact original descriptor digest and either its single original absolute
MainThreadChecker token or JSON null for explicitly preserved absence. These are concrete
original hashes; no placeholder or guessed CI identity is accepted.

Run run.py with --app pointing at the exact controller checkout, --admission at
that reviewed tracked JSON, and fresh --work / --evidence directories outside
the checkout. It requires an actual ARM64 Mac, the same Xcode27 version as the
original build, and a successful original consumer with qualified native boundary
evidence plus an explicitly BUILD_ONLY UI runner.

Native descriptors must retain their original single v2 configuration, and
native enumeration must report the actual AnytypeTests plan. The frozen UI-only
generator has no named test plan: its descriptor must remain v1 with exactly
the PinkhaStage1AcceptanceUITests blueprint and no explicit TestPlan or
TestConfiguration fields. The one UI enumeration container's actual plan string
is recorded as observed metadata; it is not inferred from the scheme name.
Exactly one enabled owned UI method and no errors, extras or overlap remain
mandatory.

A copied descriptor may relocate only its explicitly admitted original
MainThreadChecker token to the verified regular Mach-O library in the selected
available ARM64 iOS27 runtime. The shared normalizer's old SDK default stays
unchanged. Its reviewed helper SHA-256 is pinned, and the receipt records the
original/replacement token, runtime and library hash. Reversing only that token
must recover every other testing-environment field exactly. Explicit absence
adds no injection, and original descriptor bytes are never edited.

Both enumeration and actual execution carry the exact full selector as separate
-only-testing argv, as well as the copied plist binding. This follows the observed
SDK enumeration portability result. Exactly one started/passed test is required
for each stage; only this new preparation and new journey may execute.

Every Products member is checked against its original kind, mode, byte count and
SHA-256. Only self-contained relative links are admitted; an external/escaping
link stops the controller for separate source/dependency review. The original
descriptors and copied bindings remain unchanged, and all restored original
Products are verified again after execution. The observer's raw on-disk capture
and reopen JSON are checked independently against deterministic native protobuf,
native digests, real process identities, exact counts and original UI attachments.
On failure, only the three known bounded synthetic fixture/receipt files are
preserved before deleting the owned simulator. Account storage and keychain
material are never exported.

The new Python controls test source/owner replay refusal, opaque block changes,
wrong runtime/test identities, explicit full selector argv, archive link/digest
admission, descriptor immutability and post-execution product integrity. Their
result is controller evidence only; it is not actual Mac or product acceptance.
